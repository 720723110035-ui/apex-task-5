# ShopMart - Online Shopping Website

## Project Description
ShopMart is a responsive online shopping website developed using HTML, CSS, and JavaScript as part of the ApexPlanet Web Development Internship Task 5.

## Features
- Responsive Design
- Navigation Bar
- Hero Section
- Product Listing
- Search Products
- Product Category Filter
- Add to Cart
- Contact Form Validation

## Technologies Used
- HTML5
- CSS3
- JavaScript
